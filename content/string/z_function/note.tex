\texttt{z[i]} 是 $s[1\ldots n]$ 与后缀 $s[i\ldots n]$ 的最长公共前缀长度。

模式串 $p$ 在文本 $t$ 中匹配时，构造
\[
  u=p+\# +t,
\]
其中分隔符不出现在两个原串中。对 $u$ 求 Z 函数；文本对应位置的 $z$ 值至少为 $|p|$，就表示模式从该处出现。使用本章的 $1$ 下标模板时，可写成 \texttt{u = " " + p.substr(1) + "\#" + t.substr(1)}。

判断某个后缀是否以长度 $k$ 的前缀开头，只需检查 \texttt{z[i] >= k}。枚举所有满足 $i+z[i]-1=n$ 的位置，还可得到同时为前缀与后缀的长度。
