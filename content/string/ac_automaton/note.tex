依次调用 \texttt{add(pattern,id)} 加入模式串，全部加入后调用一次 \texttt{build()}。
对文本调用 \texttt{query(text)}，返回值 \texttt{ans[i]} 包含所有在位置 \(i\) 结尾的模式串编号。

\texttt{fail} 指向当前状态表示串的最长真后缀状态。
\texttt{out} 进一步跳到最近的、保存了模式串编号的 fail 祖先，因此查询时不必遍历整条 fail 链。

\begin{icpcwarning}[使用前确认]
  \begin{itemize}
    \item \texttt{build()} 会补全自动机转移，调用后不要继续加入模式串。
    \item 查询复杂度包含实际输出的匹配数量；若只需统计次数，应改用 fail 树或逆 BFS 累加。
    \item 相同模式串可以保存多个编号，并会在同一结束位置全部返回。
  \end{itemize}
\end{icpcwarning}
