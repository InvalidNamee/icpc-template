Hierholzer 算法先沿未使用的边深入，回退时把顶点加入答案，最后反转得到欧拉路径。
有向边用 \texttt{add(u,v)}，无向边用 \texttt{addu(u,v)}，构造答案用 \texttt{run(s)}。

\begin{itemize}
  \item 有向图欧拉回路：每个顶点入度等于出度；欧拉路：起点出度比入度多 $1$，终点入度比出度多 $1$。
  \item 无向图欧拉回路：所有非零度顶点度数为偶；欧拉路：恰有 $0$ 或 $2$ 个奇度顶点。
  \item 还需检查所有有边顶点属于同一个连通块；模板中边数不匹配时会返回空路径。
\end{itemize}
