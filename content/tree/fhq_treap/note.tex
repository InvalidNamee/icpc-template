使用 \texttt{FHQ T} 建立一个初始为空的有序多重集合。

\textbf{对外接口}

\begin{itemize}
  \item \texttt{insert(x)}：插入一个 $x$；
  \item \texttt{erase(x)}：若 $x$ 存在，删除一个 $x$；
  \item \texttt{rank(x)}：返回小于 $x$ 的元素个数加一；
  \item \texttt{kth(k)}：返回第 $k$ 小，$k$ 从 $1$ 开始；
  \item \texttt{pre(x)}、\texttt{nxt(x)}：返回严格小于、严格大于 $x$ 的最近元素。
\end{itemize}

不存在的前驱、后继或第 $k$ 小返回 \texttt{nullopt}。

\textbf{内部操作}

FHQ Treap 只需要三个结构操作：

\begin{itemize}
  \item \texttt{split\_lt(p,x,a,b)}：按值拆成 $<x$ 与 $\ge x$；
  \item \texttt{split\_le(p,x,a,b)}：按值拆成 $\le x$ 与 $>x$；
  \item \texttt{merge(a,b)}：要求 $a$ 中所有值不大于 $b$ 中所有值。
\end{itemize}

模板没有回收删除结点，因此空间按总插入次数增长；需要控制空间时再加入空闲结点回收。
