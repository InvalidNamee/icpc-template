固定根后，从叶子向上计算：
\[
  h(u)=\operatorname{ID}\left(
  \operatorname{sort}\{h(v):v\text{ 是 }u\text{ 的儿子}\}
  \right).
\]
叶子的儿子哈希序列为空。
排序消除了儿子原有编号和邻接表顺序的影响；相同序列通过全局 \texttt{map} 得到相同整数编号。

\textbf{函数接口}

\begin{itemize}
  \item \texttt{tree\_hash(g,u,p=0)}：返回以 $u$ 为根、不经过父亲 $p$ 的有根树编号；一般直接传 \texttt{tree\_hash(g,root)}。
  \item \texttt{tree\_id.clear()}：开始一批互相比较的树之前调用一次；这一批树计算过程中不能清空。
\end{itemize}

两棵有根树同构，当且仅当根的编号相同。
比较无根树时，先分别找到一个或两个重心，以每个重心为根计算编号，再排序比较这两个长度为 $1$ 或 $2$ 的编号数组。

这里的 \texttt{map<vector<int>,int>} 是树形离散化，不是概率哈希，所以没有随机碰撞；若需要对每个根计算答案，应改用换根哈希。
